# POL-08 — Attributable audit events

Version: 1.0

Status: authored exercise criterion

Authentication, MFA, role changes, deactivation, service-request updates, change decisions,
deployments, rollbacks, backups, and restores must create structured events with run, actor,
correlation, object, result, and timestamp fields where applicable.

This is a project-authored lab criterion, not a statement of production logging coverage.

# POL-03 — Privileged authentication and access review

Version: 1.0

Status: authored exercise criterion

Privileged portal actions require a valid authenticated session and completed TOTP verification.
The fictional organization performs a quarterly review covering the complete active and disabled
account population, with attributable decisions and referenced follow-up actions.

This is a project-authored lab criterion, not a regulatory quotation. TOTP is not described as
phishing-resistant authentication.
